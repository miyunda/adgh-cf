# v0.1.0

首次 0.x 发布：提供家庭网络 Cloudflare IPv4 优选、下载专用代理和 AdGuard Home 现有规则自动更新。源码不依赖第三方 Go 包，提供 Linux amd64/arm64 静态二进制。

更新：

- 新增 `--version`，构建注入版本与提交。
- 增加显式配置的通用 HTTP 健康检查；现有配置省略 healthMode 时保持 OpenBao 判断。
- 提供 GitHub Actions Linux 构建、测试及草稿 Release，附件含 SHA256。
- 文档集中至 docs，增加发布、升级和安全说明；示例使用通用占位域名与网络地址。

从没有版本号的本地版本升级：

- 必须保留真实 JSON 配置、.env 和状态；不要使用新的通用示例覆盖配置。
- 本版添加兼容的可选健康字段与状态中的判断规则标记，不要求迁移，也不要求更换已安装的 service/timer。首次用新版执行 run 会重置既有连续胜出次数；改变健康判断规则也会重置。若之后降级，通用 HTTP 新字段需先从旧程序的配置移除。
- 本版不修改日志输出行为，无需为本项目配置新 logrotate。
- 停 timer，等待 service 完成，备份程序与状态，核对 SHA256 后替换二进制，使用原配置 dry-run，再恢复 timer。完整流程见 docs/RELEASING.md。

限制：0.x 阶段尚未承诺接口稳定；arm64 交叉编译但未原生执行验证。家庭 dry-run 和定时器安装已由用户验证，真实 DNS 切换/回滚仍需实际验收。没有自动自更新。
