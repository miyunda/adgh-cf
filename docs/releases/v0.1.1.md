# v0.1.1

精简定时运行日志，完整测量报告继续保存到文件。

更新：

- `run --output` 保存完整 JSON 后只输出一行优化摘要，包含当前/建议/拟切换地址、确认次数、原因、实际动作与报告位置；pending 恢复及 dry-run 阻止变更也会输出决定。
- `probe --output` 保存完整 JSON 并提示路径，不再重复向 stdout 输出报告。
- `probe`、`run` 默认保留候选源状态、TCP 阶段、测速汇总及错误；逐样本和淘汰进度通过 `--verbose` 临时开启。详细样本和淘汰原因始终保留在报告。
- 未指定 `--output` 时 stdout 仍输出完整 JSON；`refresh`、`export` 的输出行为不变。

从 0.1.0 升级：

- 无需修改现有 service/timer、JSON 配置、凭据或 optimizer 状态；默认 service 已指定 `--output /var/lib/adgh-cf/last-run.json`，替换二进制即可应用日志精简。
- 若脚本同时指定 `--output` 并解析 stdout JSON，改为读取指定报告文件，或移除 `--output` 后解析 stdout。
- 停 timer，等待 service 完成，备份二进制和状态，校验升级包后替换程序；使用原配置 dry-run，确认正常后恢复 timer。具体操作见 [RELEASING.md](../RELEASING.md)。
- 升级不会删除历史 journal，也不修改主机日志轮转。报告同名替换；发生未产出报告的执行故障时，旧报告仍保留，应以 journal 中的错误与报告时间为准。

限制：Linux arm64 为交叉编译产物，未原生运行验证；目标主机升级后的日志效果、实际 DNS 切换和回滚仍需真实环境验收。DNS 选择和写入策略保持不变。
